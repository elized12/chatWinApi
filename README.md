# ChatWinApi

**ChatWinApi** — Это чат на C++ с использованием WinAPI и собственной реализации сокетов.

## О проекте

Данный проект реализует клиент-серверный чат с поддержкой многопоточности, асинхронной передачи сообщений и удобной архитектурой. Основная цель — предоставить простой и расширяемый фреймворк для общения между пользователями через TCP/IP.

- **WinAPI GUI**: современное окно чата с поддержкой Unicode.
- **Собственная реализация сокетов**: абстракция над WinSock2, поддержка TCP/UDP.
- **Многопоточная очередь**: безопасная обработка сообщений.
- **Стейт-машина**: управление состояниями приложения.
- **Система событий и колбеков**: гибкая обработка логики чата.

## Структура проекта

include/ # Заголовочные файлы библиотеки сокетов и компонентов
src/ # Реализация сокетов, адресов, фабрики и WinAPI-инициализации
logics/ # Логика чата: сервер, клиент, обработка сообщений, структуры данных


## Основные компоненты

- [`TcpSocket`](include/socket/tcpsock.h): TCP-сокет с поддержкой асинхронного accept.
- [`Server`](logics/components/server/server.h): серверная часть, обработка подключений и сообщений.
- [`Sender`](logics/components/sender/sender.h): отправка сообщений клиентам и серверу.
- [`thread_safe_queue`](logics/struct/thread_safe_queue.h): потокобезопасная очередь для задач.
- [`Message`](logics/models/message.h): структура сообщения.
- [`ListUser`](logics/struct/listuser.h): список пользователей.
- [`StateMachine`](logics/other/statemachine.h): управление состояниями приложения.

## Как запустить

1. Откройте проект в Visual Studio или любой другой IDE с поддержкой C++ и WinAPI.
2. Соберите проект (Release/Debug).
3. Запустите программу

## Требования

- Windows 10/11
- Компилятор с поддержкой C++17 и WinAPI
- [CMake](https://cmake.org/) (опционально)
